Listas Ordenadas

Exemplo de lista:

  1. Acordar
  2. Ligar para o João
  3. Tomar café
  4. Escovar os dentes
  5. Ir para a faculdade
  6. Almoçar
  7. Ir para o trabalhado
  8. Voltar para casa
  9. Jantar
  10. Dormir

A lista acima pode ser criada usando a tag OL e para cada item de lista, use a tag LI.
Você também pode mudar o tipo de lista passando o TYPE como parâmetro dentro da tag OL.
Existem quatro tipos: 1, A, a, I e i. Além de poder mudar o índice de início da lista com a tag START e o número de . Ex.:

  1. Levantar
  2. Arrumar a cama
  3. Ir ao parque
  4. Fazer exercícios
  1. Beber água
  2. Falar com João
  3. Voltar para casa
  1. Fazer um lanche
  2. Ir pescar
  3. Pegar um peixe
  1. Voltar para casa
  2. Comer o peixe
  3. Descansar

Listas Não Ordenadas

Uma lista onde não existe numeração dos itens. Não importa a ordem, o que importa é se os ítem aparecem ou não na lista.

  • Pão
  • Leite
  • Tomate
  • Alface
  • Manteiga
  • Arroz
  • Feijão

Esse tipo de lista também pode ser personalisada.
Na tag TYPE, você tem três opções: DISK (disco), CIRCLE (circulo) e SQUARE (quadrado).

Existem níveis de lista, ou seja, um item da lista, pode ter outra lista dentro dele, e em outro item dessa lista também pode conter outras listas, e assim por diante.

Há ainda um terceiro tipo de lista:

Lista de Definição

Termo
Definição

Esse tipo de lista não possue marcação, apenas um recuo para a definição.
Use a tag DL para ter essa lista. O termo usa a tag DT e a definição desse termo, a tag DD. Veja: 

    <dl>                      <!-- Abertura de lista -->
        <dt>Termo</dt>        <!-- Item da lista -->
        <dd>Definição</dd>    <!-- Definição do item da lista -->
    </dl>                     <!-- Fechamento de lista -->

Exemplo:

HTML
Linguagem de marcação para a criação do conteúdo de um site.
CSS
Linguagem de marcação para a criação do design de um site.
JavaScript
Linguagem de programação para a criação de interatividade de um site.
