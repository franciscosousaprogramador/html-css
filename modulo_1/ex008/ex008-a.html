Texto marcado

Podemos criar também um texto marcado usando a tag MARK.

E no outro parágrafo, temos outro texto marcado no final.

Uma forma de mudar a cor do marcador, use:

style="background-color: cor" dentro da tag MARK.
Essa forma é aplicada somente ao marcador que tem a tag STYLE.

Outra forma, é criar uma tag STYLE dentro de HEADER.
Ex.:

<style>
....mark {
........background-color: limegreen;
....}
</style>

Esse método é aplicado a todos os markers desta página.

Existe ainda uma terceira técnica que consiste em criar um arquivo CSS separado para colocar os estilos.
Essa forma permite, por meio de um link, usar o mesmo estilo em várias páginas sem ter que duplicar código.

Texto grande e pequeno

Estamos criando um texto grande e um texto pequeno nesse parágrafo.
Para deixar o texto no tamanho maior, a tag BIG foi utilizada. Mas ela se tornou obsoleta.
Ainda funciona, porém não é mais usada.
Lembra que o HTML é semântico, e tags quem possuiam apenas forma agora são usadas de outra maneira, agora dentro do CSS.
Tipo: Em vez disso, use isso.

Para deixar o texto pequeno, foi usada a tag SMALL.

Texto deletado

Podemos marcar um texto como excluído para indicar que ele deve ser lido, mas não cosiderado.
Nesse Caso, usa-se a tag DEL, e o texto será riscado. (Tá lá, deve ser lido, mas não considerado.)

Texto inserido

Podemos marcar um texto como inserido para dar uma ênfase e indeicar que ele foi adicionado depois.
Nesse texto, o sublinhado é adicionado por meio da tag INS.

Existe tembém o sublinhado com a tag U (não semântica).

Texto sobreescrito

Para inserir coisas do tipo x20+3.
Usa-se a tag SUP para adicionar um texto logo acima do texto.

Texto subscrito

Para inserir coisas do tipo H2O.
Usa-se a tag SUB para adicionar um texto logo abaixo do te
