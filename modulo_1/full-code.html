Ex004 - 31/10/2025

O que é "favicon"?

Um favicon é um pequeno ícone que representa um site na aba do navegador,
na barra de favoritos, no histórico de navegação e nos resultados de busca.

Ele é a abreviação de "ícone favorito" ("favorite icon")
e serve para ajudar os usuários a identificar sites rapidamente,
além de reforçar a identidade visual de uma marca.

Para usar, digite dentro da tag <head>

<link rel="shortcut icon" href="caminho-da-imagem" type="image/x-icon">

subistitua "caminho-da-imagem" pelo título da imagem;
se estiver dentro de uma subpasta, especifique o caminho: nome-da-pasta/nome-da-imagem.ico

Hierarquia De Títulos

Existem níveis de títulos que vão do h1 até o h6.

<h1>: Título principal


Que aparece no topo da página

<h2>: Sub-Título


Introduz um assunto.

<h3>: Título abaixo de Sub-Título


Traz um tópico dentro do assunto.

<h4>: Título dentro do título abaixo do sub-título.


Traz um sub-tópico dentro do tópico do assunto.

<h5>: Nível abaixo do h4.

Traz mais um nivel de sub-tópico dentro do sub-tópico do tópico do assunto.

<h6>: Título dentro do título h5.

Traz mais outo nivel de sub-tópico dentro do sub-tópico h5 dentro do sub-tópico h4 dentro do tópico h3 do assunto.

Texto marcado

Podemos criar também um texto marcado usando a tag MARK.

E no outro parágrafo, temos outro texto marcado no final.

Uma forma de mudar a cor do marcador, use:

style="background-color: cor" dentro da tag MARK.
Essa forma é aplicada somente ao marcador que tem a tag STYLE.

Outra forma, é criar uma tag STYLE dentro de HEADER.
Ex.:

<style>
....mark {
........background-color: limegreen;
....}
</style>

Esse método é aplicado a todos os markers desta página.

Existe ainda uma terceira técnica que consiste em criar um arquivo CSS separado para colocar os estilos.
Essa forma permite, por meio de um link, usar o mesmo estilo em várias páginas sem ter que duplicar código.

Texto grande e pequeno

Estamos criando um texto grande e um texto pequeno nesse parágrafo.
Para deixar o texto no tamanho maior, a tag BIG foi utilizada. Mas ela se tornou obsoleta.
Ainda funciona, porém não é mais usada.
Lembra que o HTML é semântico, e tags quem possuiam apenas forma agora são usadas de outra maneira, agora dentro do CSS.
Tipo: Em vez disso, use isso.

Para deixar o texto pequeno, foi usada a tag SMALL.

Texto deletado

Podemos marcar um texto como excluído para indicar que ele deve ser lido, mas não cosiderado.
Nesse Caso, usa-se a tag DEL, e o texto será riscado. (Tá lá, deve ser lido, mas não considerado.)

Texto inserido

Podemos marcar um texto como inserido para dar uma ênfase e indeicar que ele foi adicionado depois.
Nesse texto, o sublinhado é adicionado por meio da tag INS.

Existe tembém o sublinhado com a tag U (não semântica).

Texto sobreescrito

Para inserir coisas do tipo x20+3.
Usa-se a tag SUP para adicionar um texto logo acima do texto.

Texto subscrito

Para inserir coisas do tipo H2O.
Usa-se a tag SUB para adicionar um texto logo abaixo do texto.

Outras formatações

código-fonte / Pré formatado

O comando document.getElementById('teste') é escrito em linguagem javascript.

O código abaixo está na linguagem python.

        
    num = int input('Digite um número:')

A tag CODE faz com que o texto seja monoespaçado, ou seja, cada caracter vai ocupar o mesmo espaço.
A tag PRE engloba o texto inteiro considerando parágrafos, espaços e quebras de linha. Dessa forma, tudo o que for escrito no código vai aparecer exatamente igual na página.

Citações simples

São citações mais curtas ou sem quebras de linha.

Como diria o pai de um amigo: o computador é um burro muito rápido.

Para adicionar aspas à citação, foi usado a tag Q. Não somente aspas "", pois neste caso, faz referência a uma frase dita por alguém especíco, que no exemplo é o pai de um amigo, que traz um sentido e um significado.

Apenas adicionar as aspas manualmente no código, traz apenas a forma. Ex.: "Mais ou menos interessante". É uma frase comum que pode ser dita por qualquer pessoa e não traz uma referência especíca e pode ser aplicada a várias coisas. Assim, as aspas podem ser usadas diretamente no texto sem ter que usar esta tag.

Portanto, sempre que for citação ou algo dito por alguém especíco mencionado, use a tag Q.

Listas Ordenadas

Exemplo de lista:

  1. Acordar

  3. Tomar café

A lista acima pode ser criada usando a tag OL e para cada ítem de lista, use a tag LI.
Você também pode mudar o tipo de lista passando o TYPE como parâmetro dentro da tag OL.
Existem quatro tipos: 1, A, a, I e i. Além de poder mudar o índice de início da lista com a tag START e o número de início. Ex.:

  1. Levantar
  2. Arrumar a cama
  3. Ir ao parque
  4. Fazer exercícios
  1. Beber água
  2. Falar com João
  3. Voltar para casa
  1. Fazer um lanche
  2. Ir pescar
  3. Pegar um peixe
  1. Voltar para casa
  2. Comer o peixe
  3. Descansar

Listas Não Ordenadas

Uma lista onde não existe numeração dos ítens. Não importa a ordem, o que importa é se os ítem aparecem ou não na lista.

  • Pão
  • Leite
  • Tomate
  • Alface
  • Manteiga
  • Arroz
  • Feijão

Esse tipo de lista também pode ser personalisada.
Na tag TYPE, você tem três opções: DISK (disco), CIRCLE (circulo) e SQUARE (quadrado).

Existem níveis de lista, ou seja, um item da lista, pode ter outra lista dentro dele, e em outro item dessa lista também pode conter outras listas, e assim por diante.

Há ainda um terceiro tipo de lista:

Lista de Definição

Termo
Definição

Esse tipo de lista não possue marcação, apenas um recuo para a definição.
Use a tag DL para ter essa lista. O termo usa a tag DT e a definição desse termo, a tag DD. Veja: 

    <dl>                      <!-- Abertura de lista -->
        <dt>Termo</dt>        <!-- Item da lista -->
        <dd>Definição</dd>    <!-- Definição do item da lista -->
    </dl>                     <!-- Fechamento de lista -->
