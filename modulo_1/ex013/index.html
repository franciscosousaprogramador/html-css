O estilo CSS é feito na mesma linha que o HTML

E todas as configurações também na mesma linha

Usar estilos CSS dessa forma, não é recomendado para páginas grades ou sites que têm muitas páginas, uma vez que o trabalho se torma muito maior.
Isso porque o DEV terá que modificar cada parte do código manualmente, que por sua vez,
também fica muito poluído e difícil de entender o que é conteúdo HTML e o que é estilo CSS se estão todos na mesma linha.
