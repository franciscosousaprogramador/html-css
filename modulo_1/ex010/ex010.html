Trabalhando com links

Usando links externos

Você pode acessar o meu repositório público no GitHub

Você também pode acessar meu canal gratuito no YouTube

Para usar um link externo, use a tag A. Veja como:

<p>Você pode acessar o meu <a href="link-de-redirecionamento">repositório público no GitHub</a></p>

Para abrir o link em uma nova guia, use atributo TARGET igual a "_blank" e REL igual a "external". Veja:

<p>Você pode acessar o meu <a href="link-de-redirecionamento" target="_blank" rel="external">repositório público no GitHub</a></p>

Isso deve ser feito SEMPRE que o link redirecionar o usuário para um site externo que não pertence a VOCÊ.
Como o exemplo acima, que direciona para o repositório público do professor Gustavo Guanabara no GitHub.

Para link que redirecionam para páginas dentro do seu próprio site, o atributo TARGET recebe o valor "_self".

Usando links internos

Esta é a primeira página do site. Se você quiser, pode acessar também a minha segunda página.

Você também pode acesar a nossa terceira página


A terceira página está dentro de uma pasta. Assim, para acessar, indique o caminho completo do arquivo: pasta/arquivo.html

A terceira página possui um link para voltar para esta página. Porém como está em uma pasta, no código html, é necessário indicar para voltar uma pasta para encontar o arquivo desta página.

Veja o comando da página 1 para a 3:

<p>Você também pode acesar a nossa <a href="pasta/arquivo.html" target="_self" rel="next">terceira página</a></p>

Veja o comando da página 3 voltando para a 1:

<p>Esta é a terceira página</p>
<p><a href="../ex010.html">Voltar para a primeira página</a></p>
